# 📱 Exercícios de DMO1 
> Este repositório contém os projetos, atividades e exercícios desenvolvidos nas aulas de Dispositivos Móveis 1.


### 📌 Descrição 
Os projetos são desenvolvidos utilizando a linguagem **Kotlin**, focando no aprendizado da sintaxe, lógica de programação e fundamentos para o desenvolvimento mobile. 

---

### 📚 Conteúdo por Aula

#### [Aula 01] Introdução ao Kotlin e Conceitos Básicos
> Entrada e saída de dados, manipulação de Strings e operações matemáticas básicas.

#### [Aula 02] Estruturas de Condição e de Repetição
> Estruturas de controle de fluxo, validação e tratamento de entradas nulas.
